# SmartClick Assistant

تطبيق أندرويد تجريبي بواجهة عربية لتنفيذ نقرات متكررة على عنصر واجهة يطابق نصًا يحدده المستخدم، عبر Android Accessibility Service.

## بناء APK
ينفذ GitHub Actions بناء APK عند كل push إلى فرع `main`. بعد اكتمال المهمة، افتح تبويب **Actions** في المستودع، واختر أحدث تشغيل ناجح، ثم نزّل **SmartClick-debug-apk** من قسم Artifacts.

## الاستخدام
1. ثبّت APK على جهاز Android.
2. افتح التطبيق واختر «فتح إعدادات إمكانية الوصول»، ثم فعّل SmartClick يدويًا.
3. أدخل النص الظاهر على الزر المطلوب والفاصل الزمني.
4. اضغط «بدء النقر» ثم افتح التطبيق المستهدف.
5. اضغط «إيقاف النقر» لإيقاف العملية.

## القيود
- هذه نسخة أولية؛ لا تنقر إلا على العناصر التي تعرضها شجرة إمكانية الوصول وتسمح بالنقر.
- قد لا تعمل مع عناصر Canvas أو واجهات محمية أو تطبيقات لا تعرض عناصرها للخدمة.
- لا تستخدم نافذة عائمة أو صلاحية overlay أو root، ولا تتصل بخادم خارجي.
- يجب تفعيل خدمة إمكانية الوصول يدويًا. هذا بناء Debug للاختبار، وليس إصدارًا موقّعًا للنشر في المتجر.
